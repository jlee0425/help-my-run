# M5 Web + PWA Rewrite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Expo app with a responsive website + PWA served from the Go binary, with owner login, in-UI Garmin login (MFA), Claude-Code status card, and Web Push — per `docs/superpowers/specs/2026-07-09-m5-web-pwa-design.md`.

**Architecture:** New `web/` Vite+React+TS SPA embedded into the Go server via `go:embed` (single origin/binary). Backend gains `internal/auth` (argon2id + sessions), `internal/webpush` (VAPID), a Garmin login manager driving a new worker `login-web` mode, and small endpoint extensions. `internal/push` (Expo) and `app/` are deleted.

**Tech Stack:** Go 1.22 (chi, goose, modernc sqlite, `golang.org/x/crypto/argon2`, `github.com/SherClockHolmes/webpush-go`), Python worker (garminconnect), Vite + React 19 + TypeScript + react-router v7 + TanStack Query v5 + vite-plugin-pwa (injectManifest) + Vitest/RTL, `@fontsource` Space Grotesk + JetBrains Mono.

## Global Constraints

- Claude is **subscription-only** via `claude -p`; never introduce `ANTHROPIC_API_KEY` usage. Optional headless credential = `claude setup-token` value injected as `CLAUDE_CODE_OAUTH_TOKEN` env.
- One origin: the SPA never configures a backend URL; all fetches are relative (`/api/...`). No CORS anywhere.
- Design fidelity to the claude.ai/design project ("RUNNING ON AI"): tokens in Task 5's `tokens.css` are canonical; JetBrains Mono for `// SECTION` labels/numerals; Space Grotesk elsewhere; dark-only UI.
- Accepted deviations (spec §5.4): no "Start run" button (→ "Details"), 8-step onboarding (adds SECURE), readiness card shows color word + drivers (no /100 score), 6th signal tile is VO2MAX (Garmin training-readiness score isn't fetched), run-detail intervals hidden in v1 (no lap data stored).
- Every task ends green: `cd backend && go test ./...`, `cd garmin-worker && . .venv/bin/activate && python -m pytest tests -q`, `cd web && npm test` (once web exists).
- Commit after every task (conventional message given per task).
- Credentials discipline: Garmin email/password/MFA go over stdin to the worker, are never logged, never persisted, never in argv/env.

export class ApiError extends Error { constructor(public status:number, message:string){super(message);} }
let onUnauthorized: (() => void) | null = null;
export function setOnUnauthorized(fn: () => void){ onUnauthorized = fn; }
export async function api<T>(path: string, init?: RequestInit): Promise<T> {
  const res = await fetch(path, { credentials:'same-origin',
    headers: init?.body ? {'Content-Type':'application/json'} : undefined, ...init });
  if (res.status === 401) { onUnauthorized?.(); throw new ApiError(401,'unauthorized'); }
  if (!res.ok) {
    let msg = res.statusText;
    try { msg = (await res.json()).error ?? msg; } catch { /* non-JSON */ }
    throw new ApiError(res.status, msg);
  }
  if (res.status === 204) return undefined as T;
  return res.json() as Promise<T>;
}
export const apiGet = <T,>(p:string)=>api<T>(p);
export const apiPost = <T,>(p:string, body?:unknown)=>api<T>(p,{method:'POST',body:body?JSON.stringify(body):undefined});
export const apiPut  = <T,>(p:string, body:unknown)=>api<T>(p,{method:'PUT',body:JSON.stringify(body)});
export const apiDelete = <T,>(p:string, body?:unknown)=>api<T>(p,{method:'DELETE',body:body?JSON.stringify(body):undefined});

export function sparkPoints(vals:number[], w:number, h:number):string {
  const mn=Math.min(...vals), mx=Math.max(...vals), r=(mx-mn)||1;
  return vals.map((v,i)=>((i/(vals.length-1))*w).toFixed(1)+','+(h-((v-mn)/r)*h).toFixed(1)).join(' ');
}
export function areaChart(vals:number[], w:number, h:number, pad:number):{line:string;area:string} {
  const mn=Math.min(...vals), mx=Math.max(...vals), r=(mx-mn)||1;
  const pts=vals.map((v,i)=>[(i/(vals.length-1))*w, pad+(h-2*pad)*(1-(v-mn)/r)] as const);
  const line=pts.map(p=>p[0].toFixed(1)+','+p[1].toFixed(1)).join(' ');
  const area='M'+pts[0][0].toFixed(1)+','+pts[0][1].toFixed(1)+' '

import { precacheAndRoute } from 'workbox-precaching';
declare const self: ServiceWorkerGlobalScope;
precacheAndRoute(self.__WB_MANIFEST);
self.addEventListener('fetch', (e) => {
  const url = new URL(e.request.url);
  if (url.pathname.startsWith('/api/')) return;             // network-only for data
  if (e.request.mode === 'navigate') {
    e.respondWith(fetch(e.request).catch(() => caches.match('/offline.html') as Promise<Response>));
  }
});
self.addEventListener('push', (e) => {
  const d = e.data?.json() ?? {title:'Running on AI', body:'', url:'/'};
  e.waitUntil(self.registration.showNotification(d.title, { body:d.body, icon:'/icons/icon-192.png', badge:'/icons/icon-192.png', data:{url:d.url} }));
});
self.addEventListener('notificationclick', (e) => {
  e.notification.close();
  const url = e.notification.data?.url ?? '/';
  e.waitUntil(self.clients.matchAll({type:'window'}).then(list => {
    for (const c of list) if ('focus' in c) { c.navigate(url); return c.focus(); }
    return self.clients.openWindow(url);
  }));
});
